# 术语镜 · TermLens

Windows 上的中英文专业术语与词句解释工具，默认面向计算机领域。选中文字，点击旁边的朱砂红图标，即可通过自己配置的 AI 接口查看解释。

当前版本：**0.4.0** · Windows x64 · C# / WPF · MIT License

[下载 Windows 版](https://github.com/s128hy/TermLens/releases/latest) · [版本更新记录](CHANGELOG.md)

## 项目解决什么问题

阅读计算机资料、论文或技术文档时，遇到“随机森林”“gradient descent”等陌生术语，通常需要切换到搜索或聊天软件，再输入问题。术语镜把这个过程放到选区附近：划选词句后主动查询，查看面向初学者的定义、比喻和用途，再继续阅读。

本项目需要联网 AI 服务，不附带 API Key，也没有离线术语库。解释由所配置的模型生成，可能存在错误或含义判断偏差。

## 主要功能

- **划词查询**：鼠标拖选、双击或 Shift 单击选词后尝试显示查询入口；部分软件也支持选区变化通知。
- **手动关闭卡片**：点击空白、切换应用或打开设置时保留解释；点击 ×、在卡片内按 Esc 或关闭窗口才关闭。
- **词语和句子解释**：支持中文、英文术语和短句；句子查询会要求模型解释句意和关键概念。
- **入门解释卡片**：中英文名称、核心定义、原理与步骤、通俗比喻、具体例子、实际用途、常见误区与局限，以及当前含义和必要的歧义提示。
- **PDF 等应用的兼容读取**：点击图标后尝试读取选区，失败时使用临时复制方式读取，并尝试恢复原剪贴板。
- **手动与剪贴板查询**：主窗口输入，或复制文字后按 `Ctrl + Alt + D` 查询当前剪贴板。
- **补充上下文重查**：主动提供原句，帮助模型判断术语在当前语境中的含义。
- **流式显示**：逐步显示回答，支持取消、重试；不支持流式的接口可尝试“普通查询”。
- **查询历史**：本机加密保存最近 100 条完成的查询，可筛选、查看已有解释、重新查询和清空。
- **托盘运行**：暂停/恢复划词、打开设置、查询剪贴板和退出。
- **自定义服务**：填写 OpenAI 兼容接口的服务地址、API Key 和模型名称。

选区和手动查询最多 **2000 字符**，可选上下文最多 **3000 字符**。

## 安装方法

### 使用 Windows 发布包

1. 打开 [Releases](https://github.com/s128hy/TermLens/releases/latest)。
2. 下载该发布页面的 `TermLens-版本号-win-x64.zip`；已发布版本的功能以其更新记录为准。GitHub 自动生成的 `Source code` 是源码，不是可直接运行的软件。
3. 将 ZIP **完整解压**到一个文件夹，保留其中所有文件。
4. 打开解压目录，双击 `TermLens.exe`。

发布包包含 .NET 运行环境，无需另装 .NET，也无需运行安装程序。首次使用需要自行配置 AI 接口。当前提供 Windows x64 包；不提供 macOS、Linux 或 ARM64 原生包。

### 从源码构建

需要 Windows 和 **.NET 8 SDK**。项目使用 WPF / Windows Forms，不依赖第三方 NuGet 包。

在项目根目录运行：

```powershell
dotnet build .\TermLens.csproj -c Release
dotnet run --project .\TermLens.csproj -c Release
```

生成包含运行环境的 Windows x64 发布目录：

```powershell
dotnet publish .\TermLens.csproj -c Release -r win-x64 --self-contained true -o .\release\TermLens -p:DebugType=None -p:DebugSymbols=false
```

分发时请一并附上根目录的 `LICENSE`。依赖运行环境附带的许可文件也应保留。

## 使用方法

### 1. 配置接口

打开“连接与设置”，填写服务地址、API Key 和模型名称。软件支持提供 `POST /chat/completions` 的 OpenAI 兼容文本接口，以 `Authorization: Bearer ...` 鉴权。

| 服务地址示例 | 实际请求地址 |
|---|---|
| `https://example.com` | `https://example.com/v1/chat/completions` |
| `https://example.com/v1` | `https://example.com/v1/chat/completions` |
| `https://example.com/api/v3` | `https://example.com/api/v3/chat/completions` |
| `https://example.com/v1/chat/completions` | 原地址 |

以上是格式示例，不是可用的服务。模型名称由服务商决定，项目不预设模型。

点击“测试连接”，成功后点击“保存配置”。测试连接会发送“随机森林”进行一次查询，可能产生服务商费用。远程地址应使用 HTTPS；本机地址允许 HTTP。不支持仅提供 Responses API 或需要其他鉴权/请求格式的服务。

### 2. 划词解释

1. 在其他应用中选中词语或句子。
2. 松开鼠标，点击选区附近的朱砂红选词框图标。
3. 等待卡片显示解释。首次读取可能有短暂加载。
4. 可拖动卡片顶部；点击外部、切换应用不会关闭或取消查询。点击右上角 `×`、按 `Esc` 或使用窗口关闭操作才关闭。再次查询替换当前卡片。
5. 回答完成后可复制解释；需要原句帮助判断时，展开上下文输入区并重新解释。

划选本身不发送 AI 请求。兼容读取可能在点击图标时模拟 `Ctrl+C`。

### 3. 手动或剪贴板查询

- 在主窗口输入文字，按 Enter 或点击查询按钮。示例词按钮只填入文字，不自动查询。
- 也可以先复制文字，再按 **`Ctrl + Alt + D`**。该快捷键查询的是**当前剪贴板**，不会自动替你复制当前选区。
- 快捷键被占用时，可使用托盘菜单中的“查询剪贴板文字”。

关闭主窗口后程序继续在托盘运行。暂停划词后仍可手动查询；彻底退出请使用托盘菜单“退出”。软件不自动设置开机启动。

### 4. 查看历史

主窗口“查询历史”、卡片“历史”按钮或托盘“查询历史”均可进入历史列表。按词句或上下文筛选，点击一条记录直接查看已保存的解释，不联网、不要求当前接口配置有效。

卡片中的“重新查询”才会再次调用当前配置的 AI 服务，使用原词句和上下文，并更新历史。成功查询按词句与上下文去重，最近的记录置顶，最多保存 100 条。失败、取消或未完成的回答不保存；过长回答会提示未加入历史，仍可查看和复制。

历史保存在当前 Windows 用户的 `%LOCALAPPDATA%\TermLens\history.dat`，包含词句、主动填写的上下文、回答及查询时间，使用 Windows DPAPI 加密。可点击“清空历史”删除已保存记录，重启后也不会恢复。存储异常会在界面提示，不影响查看当前回答。

## 输入输出示例

以下为说明输出结构而编写的示例，不代表一次真实服务调用或固定答案；内容会随模型和上下文变化。

### 示例一：术语

**输入**：`随机森林`；上下文留空。

**可能显示的解释**：

| 项目 | 示例内容 |
|---|---|
| 中文名称 | 随机森林 |
| 英文名称 | Random Forest |
| 当前含义 | 机器学习领域的一种集成学习方法 |
| 一句话定义 | 结合多棵决策树的结果，用于分类或预测。 |
| 通俗比喻 | 像请多位评委分别判断，再汇总意见；但评委也可能犯相似的错误。 |
| 原理与步骤 | 从训练数据反复采样，分别训练决策树，再以投票或平均值汇总预测。 |
| 具体例子 | 三棵树分别把邮件预测为“垃圾、正常、垃圾”，多数投票的结果为垃圾邮件。 |
| 实际用途 | 识别垃圾邮件、预测房价等。 |
| 常见误区与局限 | 树更多并不保证解决数据偏差；单棵树的判断也不等于最终结果。 |

### 示例二：结合上下文确认含义

**输入**：`Transformer`

**主动填写的上下文**：`The transformer reduces voltage.`

**可能的输出**：中文名称“变压器”、英文名称“Transformer”，说明它在该句中指改变交流电压的电气设备，并给出比喻与用途。补充上下文有助于避免把它误解为深度学习架构。

### 示例三：句子

**输入**：`Gradient descent updates model parameters to reduce the loss.`

**可能的输出**：用“梯度下降与参数更新”作为简短标题，解释“通过更新模型参数来减小损失”的句意，再说明梯度下降、参数和损失之间的关系，并给出通俗例子及应用。句子查询仍使用同一张解释卡片。

模型没有按约定格式回答时，软件会保留并显示原始回答文本。

## 兼容性与限制

- 面向能够选择或复制文字的应用；**不支持图片识别、视频取字和没有文字层的扫描 PDF**。
- Edge PDF 的选区读取曾通过本机测试；WPS 的只读选区路径曾通过临时文档测试。Zotero、Chrome PDF、Word 及其他阅读器版本尚未完成全面实测，不能保证所有软件都兼容。
- PDF 测试使用专用测试窗口及用于定位文字的无障碍参数；不能把该结果视为所有普通浏览器配置均已验证。
- 管理员权限窗口、禁止复制的文档、远程桌面和特殊绘制界面可能无法读取。
- 未选中文字的普通拖动也可能出现入口；点击后会提示重新选词。
- 未显示图标或读取失败时，可手动复制，再按 `Ctrl + Alt + D`。
- 查询默认超时 60 秒。取消不保证免除服务商已经产生的费用。
- 解释不是联网检索的核验结果；重要结论应另行查证。

## 数据与隐私

- 仅在主动查询或测试连接时向配置的服务发送请求，发送所查询文字及主动填写的上下文。
- 不自动发送整页内容、文档路径或窗口标题。
- 兼容模式会临时复制，并尝试恢复原剪贴板；其他应用同时更新剪贴板时不会覆盖它。不支持备份的格式会提示手动复制。系统剪贴板历史和其他剪贴板管理器仍可能保留临时记录。
- 设置位于当前用户的 `%LOCALAPPDATA%\TermLens\settings.json`。API Key 使用 Windows DPAPI 加密，服务地址和模型名称为普通配置文本。
- 从 0.4.0 起，应用会在本机加密保存最近 100 条成功查询；历史包含词句、上下文与回答，可清空。不会额外向服务商上传整个历史。应用不记录密钥日志；AI 服务商的数据处理方式由其自身规则决定。

## 开发与测试

运行核心与界面回归测试：

```powershell
dotnet run --project .\Tests\TermLens.Tests.csproj -c Release
```

测试使用模拟 HTTP 响应，不访问真实模型；会生成界面预览和测试报告到 `artifacts`。当前回归包括取消与超时、流式解析、上下文、卡片替换和按需创建，以及失焦保留、历史加密与恢复、离线回看和清空等。

`--capture-probe` 可另外验证跨进程复制读取。`--selection`、`--browser-probe`、`--pdf-probe` 和 `--wps-probe` 属于依赖本机应用的交互测试，会打开测试窗口；WPS 测试会在已运行的 WPS 中创建并关闭一个临时文档。测试中断时应检查自己的测试窗口。

浏览器测试会写入专用配置目录，已有测试曾发现其中含有账号和浏览器数据，来源尚未确认；**请勿提交或分发这些目录，也不要把专用配置目录等同于绝对隔离的环境**。测试产物、浏览器配置、构建文件和发布目录已列入 `.gitignore`。

可通过 `TERMLENS_TEST_CHROME_PATH` / `TERMLENS_TEST_EDGE_PATH` 指定测试浏览器。内存对比脚本为 `Tests/Memory.ps1`，请在启动前退出当前术语镜实例；`DOTNET_ROOT` 只需在使用自定义 SDK 目录时自行设置。
